# Sources and third-party software

This release extracts a general learning workflow from a private, user-owned engineering workspace. Its personal notes, source-project firmware, conversations, local configuration and Git history are excluded. The public repository starts with a fresh history.

Obsidian is a separate application. Community plugins are downloaded on explicit `install`, directly from pinned upstream releases, and remain subject to their own licenses:

- Meta Bind: https://github.com/mProjectsCode/obsidian-meta-bind-plugin
- QuickAdd: https://github.com/chhoumann/quickadd
- Flashcard Studio: https://github.com/almalkiid/flashcard-studio

The installer and configuration in this repository are original project material; upstream plugin assets are not vendored. GPL-3.0-only covers this project's original code, configuration, documentation and SVG artwork. The verbatim GNU GPL text is provided in LICENSE.
