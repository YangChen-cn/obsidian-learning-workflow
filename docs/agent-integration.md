# 接入你的 AI 工具

本工作流提供文件协议与命令，不绑定模型服务。

1. 将项目目录提供给有文件读写能力的 Agent，让它先读 `AGENTS.md`。
2. 告诉它使用哪个 project ID。项目不在本工作流目录里的代码、阅读材料或练习，可通过来源描述、相对资料路径或公开链接引用。
3. 结束实际工作后，让 Agent 在 `.learning` 准备会话 JSON 并运行 `record`。JSON 是事实摘要，脚本不会执行其中的命令。
4. Agent 将新增价值的知识写入 Inbox；本人审核后再归档。自己的复述和实际观察写在 Practice 或学习会话中。

没有文件工具的聊天产品：让 AI 输出符合 `docs/session.example.json` 的 JSON；自行核对并保存，然后运行 Python。普通阅读也可以没有任何 tests，保留实际来源和活动摘要即可。

来源是用户明确提供的材料，不主动读取整段聊天历史。当前版本不导入或保存完整聊天；需要摘录时由用户明确提供，核对出处并仅保留相关片段。

Local REST API / MCP 可选：若你的工具已连接 Obsidian，可以用它操作笔记；本项目不配置、分发或保存 API Key。文件工具足以执行全部归档命令。

## 示例请求

> 结束这次课程学习并归档到 english。执行者是 human，我提供的证据是这段录音和这两句复述。不要推断掌握程度；如果需要澄清，一次只问一个问题。

> 结束这次 Agent 开发并归档到 my-app。执行者为 agent，记录实际修改和测试。可复用方法提炼成 Inbox 草稿，保留我的自评。
